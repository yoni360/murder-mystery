# CASE FILES — ready to play

[Download the Windows x64 EXE](https://media.githubusercontent.com/media/yoni360/murder-mystery/main/downloads/Case-Files-1.0.0-Windows.exe).

Double-click the downloaded application. No terminal, local server, account or internet is required during play. Choose Hebrew or English, print the dossier from the title menu and begin a new investigation.

Printable dossiers are in [public/dossiers](../public/dossiers). This folder includes the launch guide, SHA-256 checksum and spoiler-free QA report.

The executable is stored with Git LFS because it exceeds GitHub's normal Git file limit. Use the direct download link above. Developers cloning the project need Git LFS to retrieve this prebuilt binary; the source and Windows build script are available independently.

The executable is unsigned and was built on Linux. Actual Windows execution has not been verified. See [QA.md](QA.md) for validation coverage.
